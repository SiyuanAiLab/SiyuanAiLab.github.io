免费 Agent Skill 间接经济价值诊断：衡量仪器先行，兑现走传导链（2026-09-28）

建议判断最高判断：课题继续，但下一步不是做更多 Skill，而是先用六周建成修正版「归因仪+兑现接口」（针 1 下载计数、针 3 独立站埋点、针 4 成交信号先行，针 2 社媒渠道码降级为软归因），因为开放标准已把 Skill 本体直接付费空间结构性压缩、间接兑现链的全部链环节点思远已持有、缺的只是衡量仪器，并以「针位读数连续四周未影响任何一次决策」作为停止线。

执行摘要｜课题答案已收敛：价值只能走间接兑现链，衡量仪器是当下第一交付物

  • 事实依据课题第一问「如何衡量」的答案是当前不可衡量，且缺口是平台结构性缺口而非个人短板——SkillHub 官方 Open API 五类能力中无作者侧下载统计、用户画像与渠道归因接口，页面只暴露下载计数，第三方填坑工具的存在佐证官方缺失（对抗性检验：未推翻）。来源：SkillHub 首页实测（Playwright)
  • 建议判断课题第二问「如何兑现」的答案是不经 Skill 本体收费（本体全程免费为定调），经传导链兑现——Skill 作证明层钩子、社媒内容放大、独立站与私域沉淀、漏斗末端既有产品（199 群/内参/内训/企业定制）收费。
  • 建议判断行动序是先仪器后制品：PS1（归因仪+兑现接口）六周主线、PS2（办公垂直 Skill 套件）低功耗并行作内容弹头；归因仪、兑现接口与套件是同一漏斗的仪器-接口-制品三段，拆成三个独立产品会三条线都缺另一半。
  • 推算判断停止线预设为可证伪节点：M1.5「读数四周内无一次影响决策」即砍对应针位、M6「社媒到独立站归因转化持续为零」即停线；推算逻辑：不预测用户规模与收入数字（无证据基础），只设二元裁决点，证伪即止损。数据前提：SkillHub 首页实测（Playwright)

论点一｜行业与商业模式面：开放标准已完成 commodity 化，Skill 本体直接付费空间已被结构性压缩

证据组1｜「直接卖制品」路线已两次失效，开放标准把 Skill 变成跨平台公共品

  • 事实依据第一次失效是提示词集市：PromptBase 2022 年 6 月上线、prompt 售价约 1.99-9.99 美元、平台抽成 20%，单文本 prompt 护城河极浅，GPTs 无代码化与免费分发后该模式被边缘化。来源：Tracxn 公司档案：PromptBase
  • 事实依据平台私有插件格式的生命周期仅约一年：ChatGPT plugins 2024 年 3 月停止新建对话、4 月 9 日完全终止，死因包括参与度低、授权安全问题与启用 UX 繁琐。来源：Zapier 官方：ChatGPT plugin 日落通知
  • 事实依据官方商店直接变现路线第一次被证伪：GPT Store 延期后于 2024 年 1 月上线，上线时收入分成仍未落地，后续仅以美国 invite-only 试点推出，开发者变现承诺基本落空。来源：VentureBeat / TechCrunch：GPT Store 上线与延期报道
  • 事实依据格式战争已结束：2025 年 12 月 Agent Skills 成为开放标准，截至 2026 年 9 月官方展示的采用客户端超 40 个（含 ChatGPT & Codex、Cursor、GitHub Copilot、Gemini CLI、字节 TRAE 等竞争对手），Skill 成为跨平台 commodity。来源：Agent Skills 开放标准官网 agentskills.io
  • 事实依据货架供给已爆炸：SkillsMP 站内收录 530,778 个（其 About 页称 GitHub 公开 SKILL.md 总量 300 万+，两个口径需区分）、Smithery 15,000+、Qoder Skills 58,000+，多数平台未公布任何收费模式。来源：SkillsMP 官方 About 页
  • 建议判断两个关键转折决定了今天的格局：GPTs 免费分发边缘化了「卖 prompt 文本」，开放标准又把 Skill 从单平台资产变成跨平台公共品——直接付费空间被结构性压缩，免费 Skill 的经济价值只能走间接路径。
  • 推算判断中国线与全球线存在结构性差异：全球线是「标准先行、开发者生态驱动」，中国线是平台巨头把 Skill 直接封装进办公产品面向非开发者白领（扣子定位「职场 AI 智能伙伴」、WorkBuddy 定位可执行式办公）；推算逻辑：由两侧官方定位措辞直接对比外推，办公人群触达 Skill 的入口是平台产品而非 GitHub 或标准社区。数据前提：搜狐：WorkBuddy 开放平台正式上线

证据组2｜价值链利润在上游订阅与下游企业按调用计费两处，中游货架当下是生态税不是收入中心

  • 推算判断价值链三段拆解：上游模型与 harness 收订阅与 token 费、中游 Skill 制品与货架免费分发为主、下游场景终端里企业按调用付费；利润核心在上游与下游两处，成本核心在中游货架的审核治理与获客补贴；推算逻辑：由各环节收费机制实证拼装——订阅制、按调用计费、按量计费均已证，「中游不是利润中心」是从「免费+重审核投入」推出的结构判断。数据前提：阿里云百炼 MCP 简介（官方帮助）
  • 事实依据SkillPay（2026 年 7 月 16 日上线）是企业通道不是个人通道：创作者/企业认证+绑定微信支付商户号、封装 Pay Skill 自主定价、按调用计费结算，首批入驻清一色企业（瑞幸、携程、万得、通达信、腾讯视频 WorkRally），个人创作者收入案例零公开（对抗性检验：未推翻）。来源：央广网：腾讯上线 SkillPay
  • 建议判断中游货架的商业模式当下是「生态税」而非直接收入：免费分发+重审核+评测的价值在于为腾讯锁定 Agent 入口与开发者心智，独立作者同期能拿到的只有曝光与榜单位，没有平台分成。
  • 建议判断SkillHub 复刻应用市场的必然节奏：2026 年 3 月免费上架扩规模、7 月 SkillPay 建交易层、企业专区收割 B 端——个人作者在交易层对个人开放前入场，拿的是流量红利而非收入，这与 GPT Store 的历史路径互为镜像。

论点二｜竞争面：货架流量红利真实存在但分布极端幂律，思远与头部差 3-4 个数量级

证据组3｜头部单品百万级与极端幂律同时成立，腰部以下几乎不存在收入

  • 事实依据SkillHub 规模与天花板：10 万+至 13 万+ Skills、月下载千万级，是中国最大的 Skill 创建与分发平台（对抗性检验：未推翻）。来源：GitHub Tencent/skillhub README
  • 事实依据委托人「头部天花板千级以下」的 kill criterion 不成立：2026 年 9 月 28 日热榜实测头部个人作者单品百万级（编程专家.Skill 163.3 万、育儿大师.Skill 105.6 万、dev-expert 95.6 万），天花板在百万级而非千级（对抗性检验：未推翻）。来源：SkillHub 首页实测（Playwright)
  • 事实依据竞争基线差 3-4 个数量级：头部作者 user_741dc82b 一人三爆款合计约 300 万下载、user_814dbe54 双爆款合计超 100 万，思远自有 Skill 累计约 250 下载（委托人提供口径）——靠 Skill 分发本身养不活一人公司。来源：SkillHub 首页实测（Playwright)
  • 事实依据跨行业标杆证明免费/低价制品变现呈极端幂律：Gumroad 前 1% 产品拿走 77.3% 收入、创作者月收入中位数 72 美元、44% 产品零收入（对抗性检验：未推翻；注：「63% 卖家总收入低于 50 美元」实为 Notion 模板卖家口径，全站表述有口径偏差但方向一致），赢者通吃、分发能力大于制品质量。来源：cpengx：Gumroad 数字模板分布分析

证据组4｜替代品是大厂官方内置能力，围墙花园风险真实存在

  • 事实依据替代品配额显示用户不装第三方 Skill 也够好：豆包工作官方技能+连接器体系、WorkBuddy 100+ 官方内置技能（企业版管理员可统一推送）、钉钉 DEAP 11+ 官方技能、扣子技能商店+500+ 插件，大厂官方能力直接覆盖办公场景。来源：钉钉 DEAP 官方页
  • 事实依据大厂正把 Skill 类能力内化为平台官方功能而非开放第三方货架：QuestMobile 原文「功能/服务走向 Skill 化」，腾讯以微信+企微+腾讯文档构建自有 Skill 矩阵，豆包付费版按办公场景分层（对抗性检验：未推翻；扣子对个人开发者开放上架是部分反例，但无公开下载计数）。来源：QuestMobile 2026年AI应用市场发展半年报（澎湃转）
  • 事实依据大厂支持度分层：腾讯最开放（公开货架+下载计数+个人实名上架+SkillPay 交易层）、字节半开放（官方内置为主、第三方走 MCP 连接器）、阿里侧重 B 端（钉钉受控三方技能+百炼 MCP 市场按量计费）——围墙花园风险真实存在，但当前腾讯路线是开放货架抢生态。来源：阿里云百炼 MCP 简介（官方帮助）
  • 事实依据大厂办公 Agent 入口正在收敛：腾讯 2026 年 9 月 24 日被报道停运 QClaw、AI 办公入口整合至 WorkBuddy，「一个主力入口+一个官方货架」格局成型。来源：财新：QClaw 停运整合至 WorkBuddy

论点三｜用户痛点面：办公人群 AI 渗透已大众化，但第三方 Skill 触达存在结构性断点

证据组5｜办公人群 AI 使用已大众渗透，付费仍是少数派行为

  • 事实依据大盘足够大：中国生成式 AI 用户 5.15 亿（2025 年 6 月，半年翻番）至 6.02 亿（2025 年 12 月，普及率 42.8%），AI 对话与助手已进入大众渗透期。来源：CNNIC《生成式人工智能应用发展报告(2025)》（中新社/商务部转载）
  • 事实依据职场渗透高位：中国职场 AI 使用率在 80%-93% 区间（两个独立调研交叉印证），近一半用户把生成式 AI 当办公助手。来源：《2025职场人AI工具使用体验报告》（中国青年网转潮新闻）
  • 事实依据办公 Agent 是 2026 年增长最快的渠道形态：PC 客户端同比 +340.6%，腾讯 WorkBuddy 月活 658.2 万居第一、月人均使用 19 次；但办公 Agent 月活仅为通用助手（豆包 3.82 亿）的约 1/50，迁移仍处早期。来源：QuestMobile 2026-07 AI办公Agent监测（199IT转）
  • 事实依据办公是 Skill 的第一目标场景：Anthropic 官方预置技能全部为 Office 文档四件套（Excel/PPT/Word/PDF）并内置 skill-creator。来源：Anthropic 官方博客：Introducing Agent Skills（claude.com/blog/skills）
  • 事实依据白领与开发者是两个几乎不相交的市场：2025 中国白领最常用 AI 工具类型为办公 AI 助手 57.27%、文字处理 46.20%、通用对话 38.10%，编程辅助仅 9.52%。来源：艾媒咨询：2025中国白领AI工具类型使用率
  • 事实依据付费是少数派行为：56.7% 职场人只用免费版；AI 用户实际付费比例 9.8%（高频用户 11.7% 是低频 0.9% 的 13 倍，月消费集中 30-100 元）（对抗性检验：未推翻）。来源：腾讯研究院T-ask付费调研（36氪）

证据组6｜痛点锚点已实测：输出不准、门槛高、公文「能写不能交」

  • 事实依据输出质量是办公人群第一大痛点：57.4% 认为 AI 生成内容不够准确需二次修改，45.5% 称效率提升有限，36.8% 觉得获得感低。来源：《2025职场人AI工具使用体验报告》（中国青年网转潮新闻）
  • 事实依据门槛痛点真实存在且超三分之一：35.3% 职场人觉得 AI 使用门槛高、需按固定流程操作，「不擅长提出正确问题」是底层学习壁垒——Skill 类制品的价值主张（封装提示词与工作流）恰好对此症。来源：融管理社区《无法应用AI的人3大痛点》
  • 事实依据公文场景是质量痛点最尖锐的形态：从业者原话「用AI写的材料交上去，领导一眼就看出来」「对外的稿件一律不允许用AI」，免费工具「AI 味浓，需大量人工修改」。来源：知乎公文写作痛点帖+小宇宙播客Vol.73
  • 事实依据合规与专业化缺口同时存在：38.8% 职场人担忧 AI 数据安全隐私，56.4% 高管视「缺乏与企业直接相关的专业工具」为头部问题。来源：《2025职场人AI工具使用体验报告》（中国青年网转潮新闻）

证据组7｜「办公人群对 Skill 毫无知晓」的绝对表述已被推翻，但触达结构断点仍成立、受众必须重定位

  • 推算判断受众迁移方向成立但终点不在第三方货架：证伪段已推翻「检索不到任何办公人群视角 Skill 内容」的绝对表述——《2026 Agent Skills 技术与安全白皮书》报道记载 2026 年 1 月起非技术用户涌入、将 Skills 用于 PPT 制作/邮件清理/报销审核等办公场景；但量化知晓率仍无数据，且触达结构未变——办公 Agent 月活仅为通用助手约 1/50，办公人群消费的仍是大厂 App 内置能力而非货架制品，故受众重定位为「同行/AI 玩家+经社媒内容触达的准办公人群」维持不变；推算逻辑：以办公 Agent 与通用助手月活量级差（658 万 vs 3.82 亿）外推迁移早期性。数据前提：QuestMobile 2026年AI应用市场发展半年报（澎湃转）
  • 事实依据Claude 生态 Skill 对国内办公人群结构性不可达：Claude Code 需终端/Node.js/API 配置、claude.ai 内置 Skills 需付费套餐且中国大陆不在官方服务范围，知乎作者直言「普通用户不会去安装它、配置它」。来源：知乎《内置Claude Skills怎么玩》+ eefocus 非程序员门槛 + 澎湃 Anthropic 服务范围
  • 事实依据国内办公人群的「Skill 等价物」触达路径是平台模板与智能体：扣子模板库「复制→改人设→发布」约 15 分钟上手，但扣子低代码平台已停止新注册，低门槛入口在收紧。来源：扣子官方文档：模板库+新用户低代码入口关闭
  • 待验证假设办公人群触达 Skill 类制品的现实渠道排序（推断，可证伪）：大厂 App 内置 > 社交平台教程（小红书/抖音/B站）> 同事推荐 > 技术媒体，独立 Skill 货架不在办公人群信息半径内——kill criterion ① 方向成立，但它杀死的只是「货架直达办公人群」的幻想，不杀死课题本身。

论点四｜机会面：衡量仪器是评分最高的机会，但证伪后针位设计已降级重估

证据组8｜归因空白是平台结构性缺口，修正版针位设计已按证伪结果降级

  • 事实依据归因空白是平台结构性缺口而非思远个例：SkillHub 官方 Open API 五类能力中无作者侧下载统计/画像/渠道归因接口，无公开作者后台数据文档，第三方填坑工具 skills-data-hub（554 次下载）的存在佐证官方缺失（对抗性检验：未推翻）——衡量链第一环缺失，「仪器本身即第一交付物」成立。来源：SkillHub 首页实测（Playwright)
  • 推算判断O1 归因针位原综合分 10.4/15 为五候选最高，证伪后下修至约 9.6 仍居首位：原成熟度 4 分含「组件全成熟」前提，该前提已被推翻（小红书普通内容禁止外链与二维码、微信带参数二维码仅限已认证服务号），成熟度按 3 重估，差异化 4（归因空白未推翻）与采用可行性 5（自用系统零外部依赖）不变；推算逻辑：原公式（成熟度+差异化+采用可行性）×（痛点强度 12/15），成熟度 4→3 代入得（3+4+5）×0.8=9.6，仍高于 O3 的 8.1 与 O2 的 8.0。数据前提：SkillHub 首页实测（Playwright)
  • 推算判断修正版四级针形态：针 1（SkillHub 下载计数抓取）与针 3（独立站行为埋点）两个环节未被证伪、先行施工；针 2 社媒渠道码降级——小红书普通内容侧带参链接/二维码不可建（平台交易导流细则 2025 年 3 月生效，证伪段已核），微信公众号带参数二维码仅限已认证服务号（证伪段已核，思远账号类型待实测），降级形态为「平台内关键词回搜+私信口令」软归因；针 4（咨询/成交信号）维持；原「两周四级针全部就位」结论作废，改为「针 1+针 3 先就位、针 2 软归因同步跑、账号类型实测后再升级」；推算逻辑：以证伪段对四环节逐一核验结果为边界，保留未证伪环节、降级已证伪环节。数据前提：aifabu：微信短链接营销实战与私域引流玩法
  • 事实依据兑现接口有成熟跨行业模式参照：link-in-bio 工具生态（Linktree 曾估值 13 亿美元）证明「多平台流量→单一聚合页→分流变现」成立，思远的独立站天然就是这个聚合页，缺的是 Skill 包装卡与渠道码接入，不是新平台。来源：36氪：Linktree 估值 13 亿美元（link-in-bio 模式标杆，时效较早仅作模式参照）

证据组9｜O4 通道未对个人开放维持观察位，O5 是伴生动作并入套件

  • 事实依据O4 SkillPay 企业级通道维持观察位不投入：首批入驻清一色企业、个人能否入驻证据冲突、个人创作者收入案例零公开，综合分 3.7/15 低于剔除线；不是不值得做，是通道未对个人开放，观察触发信号=SkillPay 开放个人入驻公告或首个公开个人收入案例。来源：ai-indeed：主流 Skill 市场付费模式解析
  • 推算判断O5 货架 SEO/榜单占位是低成本伴生动作而非独立机会：改标题/简介/关键词即做、零成本，但天花板受货架流量分配逻辑控制且与 O2 共用产能；推算逻辑：成熟度 5+差异化 3+采用可行性 5、痛点强度按 9/15 计得 7.8/15，并入 O2 的上架清单不单独立项。数据前提：SkillHub 首页实测（Playwright)
  • 建议判断机会排序与结构判断：O1 归因针位 > O3 兑现接口 > O2 办公垂直套件 > O5 并入 O2 > O4 观察位；三者本质是同一漏斗的三段——O1 无 O3 则无数据可读，O3 无 O2 则无内容可导，O2 无 O1 则效果不可证，应按一个系统架构而非三个独立产品设计。

论点五｜产品选择：一个系统两个子系统是正确形态，载体选国产 harness 而格式守开放标准

证据组10｜PS1 六周路径与可证伪停止线已定稿，全部落在既有资产上

  • 建议判断系统形态为一个系统两个子系统：PS1=归因仪+兑现接口（同一仪器-管道连体，主线），PS2=办公垂直 Skill 套件（PS1 的内容弹头，低功耗并行），系统名暂定「Skill 证明链衡量与兑现系统」；分开建会三条线都缺另一半，且一人公司产能不支持三条并行线。
  • 事实依据资产约束已满足：全部设计落在思远已有资产上——SkillHub 账号（约 250 下载）、独立站 siyuanailab.com、五平台自媒体、自有 Skill 开发产能，零新平台零新团队，唯一新增外部依赖是短链服务与公众号渠道码（平台自带功能，渠道码可用性待账号类型实测）。来源：aifabu：微信短链接营销实战与私域引流玩法
  • 推算判断修正版六周节奏：W1-2 针 1+针 3 建成（两环节未被证伪）+针 2 软归因方案定稿与账号实测，W3-4 针 2 软归因上线+3 篇带归因内容发布，W5 针 4 上线+第一件套件发布，W6 端到端读数+二元结论；最大不确定项不是技术而是思远的持续运营盲区，对策为周报自动生成、人工判读压到 10 分钟/周、内容复用既有管线节奏；推算逻辑：以证伪后环节清单重排原六周路径，运营降频设计为设计目标未经验证。数据前提：aifabu：微信短链接营销实战与私域引流玩法

证据组11｜载体选国产 harness 是双保险，失败路径也沉淀回退资产

  • 事实依据PS2 载体选择是双保险：运行载体选国产 harness（WorkBuddy/扣子）而非 Claude 生态（终端/付费墙/地域三重门槛结构性不可达），SkillHub 一键安装直连 WorkBuddy 月活 658 万；但套件源码用开放标准 SKILL.md 编写，保持跨 40+ 客户端可移植，不被单一平台锁定。来源：Agent Skills 开放标准官网 agentskills.io
  • 事实依据缺口不等于需求的纪律已显式执行：办公人群 Skill 知晓度低是研究缺口不是产品需求，PS2 的需求锚点只挂在实测痛点上（57.4% 输出不准需二次修改、35.3% 门槛高、公文「能写不能交」），套件是解法假设不是需求本身，验证失败的退出条件已写入 W6。来源：知乎公文写作痛点帖+小宇宙播客Vol.73
  • 建议判断双系统失败也不亏的回退资产：PS1 失败沉淀归因规格文档+渠道码体系+「我如何用针位衡量免费 Skill」独家叙事素材；PS2 失败沉淀去 AI 味规则集（可复用思远全部写作管线）+套件源码+种子用户关系；若归因读数证明 Skill 线 ROI 持续为零，该结论本身就是终止投入的依据，省下的工时即收益。
  • 建议判断三大风险已有对策：平台风险（SkillHub 页面结构变动致针 1 失效→抓取脚本留人工读数兜底、月校一次）、运营风险（持续运营盲区→低频高质量不新增日更义务）、形态风险（大厂官方技能覆盖办公场景→差异化锚定「领域 know-how 密度」这一官方做不了的层）。

Red Flags｜三条硬约束已成立：个人无收费通道、触达断点、幂律分布

  • 事实依据Skill 直接收费通道对个人不存在：SkillPay 首批入驻全为企业、个人创作者收入案例零公开（对抗性检验：未推翻），GPT Store 变现承诺落空是历史前鉴——不要把钱押在 Skill 本体收费上。来源：央广网：腾讯上线 SkillPay
  • 事实依据「Skill 货架直达办公人群」路径当前不成立：知晓度量化数据仍缺、Claude 生态三重门槛、大厂内化三层叠加，受众必须重定位为「同行/AI 玩家+经社媒触达的准办公人群」。来源：知乎《内置Claude Skills怎么玩》+ eefocus 非程序员门槛 + 澎湃 Anthropic 服务范围
  • 事实依据幂律极端、腰部以下几乎无收入：Gumroad 前 1% 产品拿走 77.3% 收入、44% 产品零收入，思远 250 下载与头部百万级差 3-4 个数量级——Skill 的定位是证明链钩子与心智份额，不是收入本体。来源：cpengx：Gumroad 数字模板分布分析
  • 事实依据货架流量逻辑不等于付费逻辑：热榜顶部是个人作者爆款（百万级），企业官方 Skill 只有千级到万级（国泰海通 6 个合计 9.6 千、携程 2 个合计 3.1 千）——「企业付费能力强」不等于「企业 Skill 有流量」，两套物种不可混算。来源：SkillHub 首页实测（Playwright)

Yellow Flags｜口径折扣、运营盲区与套件验证缺口在动工前必须逐项核清

  • 事实依据SkillHub 热榜下载量口径未披露（是否含 ClawHub 镜像同步量未知），「百万级天花板」数字需保留一分口径折扣，重大投入决策前值得补一手核验。来源：SkillHub 首页实测（Playwright)
  • 事实依据WorkBuddy 规模数字为二手转述口径：桌面端月活约 1115 万、企业客户 3000+ 家、毛利率表述均来自转述（QuestMobile/易观原始报告付费墙后），未经一手核实。来源：雪球汇总 QuestMobile/易观/AI产品榜 WorkBuddy 数据
  • 建议判断思远持续运营盲区是最大执行风险（非技术风险）：周报自动化+判读 10 分钟/周+内容复用既有管线的对策本身未经验证，若 W3-4 内容发布断档，整套归因仪读数失去意义。
  • 事实依据套件是解法假设不是已证需求：去 AI 味效果（修改时间 30-60 分钟压到 10-15 分钟/篇）无实测，PS2 W1-2 自测关卡是唯一的验证闸口；公文场景是最高合规敏感区（「对外稿件一律不允许用 AI」），套件叙事须避开「代写公文」表述。来源：知乎公文写作痛点帖+小宇宙播客Vol.73

Open Questions｜两条 claim 未决不进入论证，关键缺口保留待核
