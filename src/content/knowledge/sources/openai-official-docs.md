# OpenAI 官方文档

> OpenAI 产品的官方文档，覆盖 GPT、Embeddings、Fine-tuning、Assistants API 和实时 API。

---

## 一、是什么

OpenAI 官方文档（platform.openai.com/docs）是 OpenAI 产品的核心参考入口，内容包括：

- GPT 系列模型的 API 使用
- Embeddings、Fine-tuning、DALL-E、Whisper 等能力
- Assistants API 和实时 API（Realtime API）
- 提示词工程指南、安全最佳实践、价格与速率限制
- 官方 Cookbook 和示例代码

它属于第 1 级信源，是判断 OpenAI 模型能力和 API 行为的最权威依据。

## 二、为什么存在

OpenAI 的模型、API 和价格更新频繁，官方文档是这些信息最集中、最及时的入口。相比第三方教程，它能避免版本错位，并直接提供可运行的代码示例。

## 三、核心机制

### 3.1 主要板块

| 板块 | 用途 | 典型入口 |
|---|---|---|
| Quickstart | 5 分钟跑通第一个 API 请求 | https://platform.openai.com/docs/quickstart |
| Prompt Engineering | 学习如何给 GPT 写提示词 | https://platform.openai.com/docs/guides/prompt-engineering |
| Function Calling | 学习函数调用与工具使用 | https://platform.openai.com/docs/guides/function-calling |
| Fine-tuning | 微调自有数据 | https://platform.openai.com/docs/guides/fine-tuning |
| Embeddings | 文本嵌入与向量检索 | https://platform.openai.com/docs/guides/embeddings |
| Realtime API | 实时语音对话 API | https://platform.openai.com/docs/guides/realtime |
| Cookbook | 可运行示例代码 | https://github.com/openai/openai-cookbook |

### 3.2 关键使用路径

- **查模型列表与价格** → API Reference / Pricing
- **学提示词技巧** → Prompt Engineering guide
- **看最新功能** → Release Notes 和 OpenAI Newsroom
- **找代码示例** → OpenAI Cookbook GitHub 仓库

## 四、常见误解

| 误解 | 真相 |
|---|---|
| OpenAI 文档只讲 API | 文档也包含大量产品指南、安全实践和价格说明 |
| 文档不会过时 | API 行为和能力持续更新，关键判断需查看 Release Notes |
| 只有开发者需要看 | 产品经理、内容创作者也能从提示词指南和价格页获得判断 |
| 第三方教程比文档更易用 | 教程可能基于旧版本，关键参数仍以文档为准 |

## 五、怎么用

### Level 0：收藏入口

把 https://platform.openai.com/docs 和 https://openai.com/newsroom 加入书签。

### Level 1：查事实

遇到 GPT 能力、API 参数或价格相关争议，直接搜索文档。

### Level 2：跟更新

订阅 OpenAI 开发者博客或 Newsroom，标记与自己的工作流相关的变更。

### Level 3：做验证

在写教程、做产品判断时，把 OpenAI 文档作为引用依据。
