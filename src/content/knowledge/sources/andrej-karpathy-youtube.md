# Andrej Karpathy（YouTube）

> 前 OpenAI 创始成员、Tesla AI 总监，用长视频把神经网络和 LLM 从第一性原理讲透。

---

## 一、是什么

Andrej Karpathy 的 YouTube 频道是 AI 领域最受认可的教育型长视频来源之一。内容覆盖神经网络基础、大语言模型原理、以及他个人使用 LLM 的工作流。视频通常 30 分钟到 3 小时，信息密度高但讲解清晰。

## 二、为什么存在

1. **填补理论与实践之间的鸿沟**：Karpathy 习惯从代码和直觉出发，把复杂机制拆成可理解的步骤。
2. **建立稳定基线**：他的讲解版本更新较慢但基础概念稳定，适合建立长期直觉。
3. **展示研究者视角**：不仅是"怎么用"，更是"为什么这样设计"。

## 三、核心机制

| 内容线 | 代表内容 | 适合谁 |
|---|---|---|
| 神经网络基础 | Neural Networks: Zero To Hero | 想从 0 理解深度学习的人 |
| LLM 原理 | Deep Dive into LLMs like ChatGPT | 想理解 GPT 内部机制的人 |
| 个人工作流 | How I use LLMs | 想把 LLM 用得更高效的人 |
| 快速概念 | Intro to Large Language Models | 需要快速建立 LLM 全局观的人 |

## 四、常见误解

| 误解 | 真相 |
|---|---|
| 必须看完 3 小时长视频 | 可以分段看，也可以先看 20 分钟总结版 |
| Karpathy 讲的内容都针对工程师 | 他的"How I use LLMs"等非技术视频对产品经理、创作者同样有用 |
| 看完就懂了 LLM | 视频建立直觉，动手实验和读文档才能补全 |
| 所有视频都代表最新能力 | 基础原理稳定，但具体产品能力要以官方文档为准 |

## 五、怎么用

### Level 0：收藏入口

频道主页：https://www.youtube.com/@AndrejKarpathy

### Level 1：选一条主线入门

- 完全零基础 → "Neural Networks: Zero To Hero"
- 想理解 LLM → "Intro to Large Language Models"
- 想优化个人工作流 → "How I use LLMs"

### Level 2：配合代码/文档

看完概念视频后，到对应官方文档或 Cookbook 找可运行示例。

### Level 3：做输出

把学到的机制用自己的话写成笔记或教程，是检验是否真懂的最好方式。
