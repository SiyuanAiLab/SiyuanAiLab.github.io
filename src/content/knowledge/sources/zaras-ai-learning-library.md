# Zara's AI learning library

> Zara Zhang 维护的免费 AI 学习资源库，面向非技术背景学习者。

---

## 一、是什么

Zara's AI learning library 是一个个人策展的网站，收集并分类展示 Zara Zhang 认为值得看的 AI 学习资源，包括精选视频、播客、X 账号、Newsletter、产品、Prompts 和 Claude Skills。

## 二、为什么存在

非技术背景学习者常被大量教程淹没。Zara 用"Follow builders, not influencers"的策展原则，把高质量、免费、可操作的资源整理成索引，降低入门门槛。

## 三、核心机制

| 入口/作品 | URL | 说明 |
|---|---|---|
| 主页 | https://zara.faces.site/ai | 资源库首页 |
| Deep Dive into LLMs like ChatGPT | https://www.youtube.com/watch?v=7xTGNNLPyMI | Andrej Karpathy 的 LLM 深度讲解 |
| Prompting 101 \| Code w/ Claude | https://www.youtube.com/watch?v=ysPbXH0LpIE | Anthropic 官方 Prompting 教程 |
| Andrew Ng: Building Faster with AI | https://www.youtube.com/watch?v=RNJCfif1dPY | YC 的 AI 加速构建访谈 |
| People to Follow on X | https://zara.faces.site/ai | 25 个 builder 型 X 账号清单 |
| Prompts / Skills | https://zara.faces.site/ai | Claude Prompts 与 Skills demo |

## 四、常见误解

| 误解 | 真相 |
|---|---|
| 这是新闻源 | 实际是教育资源索引，不适合追时效 |
| 适合直接自动化抓取 | 无 RSS/API，更新节奏不明，不适合接入自动化管线 |
| 只适合初学者 | 其中的 X 账号清单和 Prompts 对进阶者也有价值 |
| 所有资源都完全免费 | 所列资源免费访问，但部分产品可能有付费层级 |

## 五、怎么用

- **入门路径**：从 Featured Videos 和 Prompting 101 开始。
- **补充社媒情报**：把 X 账号清单导入关注列表，作为社媒情报管线的输入。
- **Skill 解读素材**：从 Prompts/Skills 区挑选与"AI + 营销/内容生产"相关的 demo。
- **建立个人书签**：把感兴趣的视频/播客放入学习清单，定期回看。
