# Midjourney 官方文档

> Midjourney 的官方使用指南，覆盖参数、指令、风格控制和订阅说明。

---

## 一、是什么

Midjourney 官方文档（docs.midjourney.com）是 AI 图像生成工具 Midjourney 的核心参考入口，内容包括：

- 参数与指令参考（如 `--ar`, `--v`, `--style`, `--sref`）
- Prompt 写法与风格控制
- 模型版本说明与切换方式
- 订阅计划与使用限制
- 社区准则和版权说明

它属于第 1 级信源，是判断 Midjourney 功能和参数行为的最权威依据。

## 二、为什么存在

Midjourney 的参数体系和模型版本更新频繁，官方文档是参数含义、版本差异和订阅规则的最准确来源。相比社交媒体上的 prompt 技巧，文档能避免误解和过时信息。

## 三、核心机制

### 3.1 主要板块

| 板块 | 用途 | 典型入口 |
|---|---|---|
| Quick Start | 新用户入门 | https://docs.midjourney.com/docs/quick-start |
| Prompts | Prompt 写法指南 | https://docs.midjourney.com/docs/prompts |
| Parameters | 参数完整列表 | https://docs.midjourney.com/docs/parameter-list |
| Model Versions | 模型版本说明 | https://docs.midjourney.com/docs/models |
| Style Reference | 风格引用（sref） | https://docs.midjourney.com/docs/style-references |

### 3.2 关键使用路径

- **查某个参数怎么写** → Parameter List
- **想了解模型版本差异** → Model Versions
- **想控制风格一致性** → Style Reference / Character Reference
- **看订阅与权限** → 账户与订阅页面

## 四、常见误解

| 误解 | 真相 |
|---|---|
| Midjourney 只靠 prompt 技巧 | 文档中的参数和模型版本控制同样关键 |
| 免费用户和订阅用户能力相同 | 不同订阅等级在 GPU 时间、商业授权上差异很大 |
| 所有教程里的参数都可用 | 参数可能随版本变化，旧 prompt 可能在新版本失效 |
| 官方文档只有英文 | 是的，但参数和指令本身是代码化表达，语言门槛较低 |

## 五、怎么用

### Level 0：收藏入口

把 https://docs.midjourney.com/ 加入书签。

### Level 1：查参数

遇到参数含义或写法问题，直接查 Parameter List。

### Level 2：跟版本

每次模型大版本更新时，查看 Model Versions 页面，确认旧 prompt 是否需要调整。

### Level 3：建立风格系统

使用 Style Reference 和 Character Reference 建立可复用的视觉风格库。
