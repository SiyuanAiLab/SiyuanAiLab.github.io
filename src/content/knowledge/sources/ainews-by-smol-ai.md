# AINews by smol.ai

> 面向 AI 工程师的技术 Newsletter，由 smol.ai 团队策展。

---

## 一、是什么

AINews by smol.ai 是一档 Beehiiv 托管的 AI 技术 Newsletter，定位是为 AI 工程师提供最新研究、工具、代码库和行业动态的精选摘要。

## 二、为什么存在

AI 工程师需要同时跟踪论文、GitHub 项目、模型更新和产品发布。AINews 通过定期摘要，把高信号内容聚合成一封邮件，减少在多个信息流之间切换的成本。

## 三、核心机制

| 入口/作品 | URL | 说明 |
|---|---|---|
| 主页/订阅 | https://ainews.beehiiv.com/ | Beehiiv 订阅入口（当前页面仅展示订阅表单） |
| smol.ai 主站 | https://smol.ai/ | 策展团队主站 |
| smol-ai GitHub | https://github.com/smol-ai | 团队开源项目集合 |
| godmode | https://github.com/smol-ai/godmode | 多模型聊天界面 |
| smol-course | https://github.com/smol-ai/smol-course | 小型 AI 课程资源 |
| 历史 issue | 需订阅后查看 | Beehiiv 页面未公开历史 issue 列表 |

## 四、常见误解

| 误解 | 真相 |
|---|---|
| 主页能看到所有历史文章 | 当前主页仅展示订阅入口，历史 issue 需订阅后查看 |
| smol.ai 只做 Newsletter | 团队同时维护多个 AI 开源工具和项目 |
| 适合所有 AI 学习者 | 内容偏工程，非技术读者可能门槛较高 |
| Beehiiv 链接永久有效 | 平台迁移或 publication 设置变化可能导致链接失效 |

## 五、怎么用

- **订阅后建立筛选规则**：把邮件归入固定标签，避免淹没收件箱。
- **结合 GitHub**：遇到工具/项目直接到仓库看更新、issue 和 star 趋势。
- **与官方文档交叉**：新模型/库的能力以官方说明为准，避免仅凭摘要做判断。
- **作为社媒情报补充**：与 X 列表、GitHub Trending 配合使用，形成工程视角的情报网。
