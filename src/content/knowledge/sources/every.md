# Every

> 以 AI 为主题的订阅媒体，集合多个专栏作者，提供深度评论和实操指南。

---

## 一、是什么

Every 是一家 AI 领域的订阅媒体公司，由 Dan Shipper 等人创立。它通过多个专栏（如 AI & I、Chain of Thought、Vibe Check、Source Code、Context Window）覆盖 AI 产品、技术、商业和文化，内容介于新闻、评论与教程之间。

## 二、为什么存在

相比单作者 Newsletter，Every 采用多专栏模式，让读者按兴趣选择深度内容。它不仅解释"为什么重要"，也提供"怎么用"的具体路径，适合希望系统理解 AI 的知识工作者。

## 三、核心机制

| 入口/作品 | URL | 说明 |
|---|---|---|
| 首页/订阅 | https://every.to/ | 主站点与订阅入口 |
| AI & I | https://every.to/s/ai-and-i | Dan Shipper 的 AI 专栏与播客 |
| Vibe Check | https://every.to/vibe-check/sonnet-5 | 模型评测与产品体验 |
| Context Window | https://every.to/context-window/codex-in-practice | OpenAI Codex 实践分析 |
| Source Code | https://every.to/source-code/claude-code-is-the-openclaw-alternative-you-already-have | Claude Code 与 OpenClaw 对比 |
| Chain of Thought | https://every.to/chain-of-thought/the-moral-of-fable | 对 Fable 模型的评论 |

## 四、常见误解

| 误解 | 真相 |
|---|---|
| Every 只是博客合集 | 它是付费订阅媒体，有编辑策略和专栏分工 |
| 免费文章足够系统学习 | 深度指南和专栏完整内容常需付费 |
| 只适合工程师 | 内容覆盖产品、商业、创作，适合各类知识工作者 |
| 多专栏会分散注意力 | 可按兴趣选择 1-2 个专栏跟踪 |

## 五、怎么用

- **选专栏**：根据角色选 AI & I（产品/创作者）或 Source Code（工程）。
- **跟模型发布**：Vibe Check 适合快速了解新模型体验。
- **付费前试读**：先看免费文章判断风格是否匹配自己的学习节奏。
- **引用时注意**：观点性文章需与官方信息区分，避免把评论当事实。
