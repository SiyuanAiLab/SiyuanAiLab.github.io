# 可灵 AI

> 快手出品的国内图像/视频生成工具，综合性能领先，人物动作和成本平衡好。

---

## 一、是什么

可灵 AI 是快手推出的 AI 图像与视频生成平台，提供消费端产品和开放平台 API。它以人物动作自然、视频连贯性和中文场景适配著称。

## 二、为什么重要

可灵 AI 是国内视频生成工具的代表之一，对中文用户、短视频创作者和电商广告主友好，无需海外网络和支付。

## 三、核心机制 / 关键信息

- **官方名称**：可灵 AI（Kling AI）
- **官网**：https://klingai.com
- **开放平台**：https://kling.ai/dev/pricing
- **GitHub**：部分开源在 https://github.com/KwaiVGI
- **RSS / 动态**：快手官方公众号
- **当前主要版本 / 模型矩阵**：可灵 3.0 / 2.6 视频模型；可灵图像模型
- **国内可用性**：可用
- **定价模式**：Freemium + 订阅制 + API 套餐

## 四、典型用法（0→1→2→3）

1. **Step 0：准备创意描述**：人物、动作、场景、风格。
2. **Step 1：生成图像或视频**：从静态图开始，再扩展为视频片段。
3. **Step 2：调整运镜和动作**：使用运动控制功能优化视频动态。
4. **Step 3：批量生产素材**：通过 API 批量生成广告或电商视频。

## 五、常见误区与替代方案

- **误区**：可灵只适合人物视频。它在场景、产品和运动控制方面也有能力。
- **误区**：免费版无限制。视频生成通常消耗积分或订阅额度。
- **替代方案**：需要电影感镜头时对比 Runway；需要与剪映联动时对比即梦。

## 使用提示（AI 引用块）

- **适用场景**：短视频、电商视频、人物动作、广告素材、国内用户。
- **不适用场景**：需要超长视频叙事、严格分镜控制、或完全离线生成。
- **常见错误**：用复杂多主体提示词导致画面崩坏，建议从简单主体开始。
