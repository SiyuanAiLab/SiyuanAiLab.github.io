# 智谱清言

> 中文理解与文化表达能力强，Agent 与工具调用能力突出。

---

## 一、是什么

智谱清言是智谱 AI 基于 GLM 系列模型开发的 AI 助手，提供对话、代码解释器、浏览器调用、长视频理解等能力。智谱 BigModel 开放平台面向开发者提供 API。

## 二、为什么重要

智谱清言在中文语义理解、古典文学、网络用语和 Agent 工具调用方面有自己的特色，是国内通用模型和代码模型的重要供应商。

## 三、核心机制 / 关键信息

- **官方名称**：智谱清言 / ChatGLM
- **官网**：https://chatglm.cn
- **开发者平台**：https://bigmodel.cn
- **GitHub**：https://github.com/THUDM
- **RSS / 动态**：智谱 AI 官方公众号 / 开放平台公告
- **当前主要版本 / 模型矩阵**：GLM 系列语言模型、GLM-4V-Plus 视觉模型、CogView / CogVideoX 等
- **国内可用性**：直连可用
- **定价模式**：按量付费 + 资源包

## 四、典型用法（0→1→2→3）

1. **Step 0：选择任务**：中文写作、长视频理解、代码解释、Agent 自动化。
2. **Step 1：体验 Agent 能力**：让智谱清言调用浏览器或代码解释器完成多步任务。
3. **Step 2：上传长视频**：测试 2 小时视频的理解和摘要能力。
4. **Step 3：接入 BigModel API**：把 GLM 能力集成到自有应用。

## 五、常见误区与替代方案

- **误区**：智谱只做学术。它的消费端产品和开放平台已经比较成熟。
- **误区**：Agent 能力对所有用户都有用。普通用户可能先从对话和写作开始即可。
- **替代方案**：需要长文本阅读时对比 Kimi；需要推理和代码时对比 DeepSeek。

## 使用提示（AI 引用块）

- **适用场景**：中文创作、智能体开发、长视频理解、代码解释器。
- **不适用场景**：只需要简单问答、对 Agent 和工具调用没有需求。
- **常见错误**：对 Agent 任务期望过高，没有明确验收标准导致循环执行。
