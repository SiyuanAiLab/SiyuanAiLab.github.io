# 月之暗面 Kimi

> 长文本处理国内领先，适合研报、合同、论文阅读和代码分析。

---

## 一、是什么

Kimi 是月之暗面（Moonshot AI）开发的大语言模型对话产品，以长上下文窗口和中文办公场景见长。

## 二、为什么重要

对于需要阅读长篇材料、做研究摘要、分析代码或写长文的用户，Kimi 提供了国内最直观的长文本体验之一。

## 三、核心机制 / 关键信息

- **官方名称**：Kimi
- **官网**：https://kimi.moonshot.cn
- **母公司**：https://www.moonshot.cn
- **开发者平台**：https://platform.kimi.ai
- **GitHub**：https://github.com/MoonshotAI
- **RSS / 动态**：月之暗面官方公众号 / 开发者公告
- **当前主要版本 / 模型矩阵**：Kimi K2.6、Kimi K2.7 Code、Kimi K2.5、Moonshot V1 等（以官方 API 文档为准）
- **国内可用性**：直连可用
- **定价模式**：消费端 Freemium + API 按量付费

## 四、典型用法（0→1→2→3）

1. **Step 0：准备长材料**：研报、合同、论文、代码仓库或书籍 PDF。
2. **Step 1：上传并提问**：要求摘要、提取关键条款、对比观点或生成读后感。
3. **Step 2：多轮追问**：针对摘要中的某个点深入挖掘，或要求生成大纲。
4. **Step 3：导出到写作工作流**：把 Kimi 的输出复制到 Notion、Obsidian 或文档中继续加工。

## 五、常见误区与替代方案

- **误区**：长上下文等于不会漏看。超长文档仍需分段验证关键信息。
- **误区**：Kimi 只适合阅读。它的代码分析和联网检索能力也值得尝试。
- **替代方案**：需要多模态或视频理解时对比豆包；需要推理和数学时对比 DeepSeek。

## 使用提示（AI 引用块）

- **适用场景**：长文档摘要、研报阅读、合同审查、代码分析、联网检索。
- **不适用场景**：需要实时语音对话、视频理解、或严格离线部署。
- **常见错误**：上传扫描版 PDF 未 OCR，导致模型无法识别文字内容。
