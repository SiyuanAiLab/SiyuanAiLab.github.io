# OpenAI / ChatGPT

> 生态最成熟的国外闭源 LLM，覆盖对话、API、图像、语音、代码和多模态，适合作为 AI 起点。

---

## 一、是什么

OpenAI 是 ChatGPT 和 GPT 系列模型的开发商。ChatGPT 是面向普通用户的对话产品，OpenAI API 是面向开发者的模型调用接口。

## 二、为什么重要

OpenAI 拥有目前最完整的模型-应用-API 生态，插件、自定义 GPT、Assistants API 等降低了非技术用户和开发者的使用门槛。

## 三、核心机制 / 关键信息

- **官方名称**：OpenAI GPT 系列 / ChatGPT
- **官网**：https://openai.com
- **对话入口**：https://chatgpt.com
- **开发者平台**：https://platform.openai.com
- **GitHub**：https://github.com/openai
- **RSS / 动态**：https://openai.com/news/rss.xml
- **当前主要版本 / 模型矩阵**：GPT-4o、GPT-4.1、o3 / o4-mini、GPT-5.5 / GPT-5.4 / GPT-5.3 Instant（以官方 API 定价页为准）、gpt-image 系列
- **国内可用性**：官方未面向中国大陆提供稳定服务；实际可用性以官方支持地区为准
- **定价模式**：按量付费 + ChatGPT 订阅；API 按输入/输出 tokens 计费

## 四、典型用法（0→1→2→3）

1. **Step 0：明确任务**：写作、分析表格、代码辅助、图像生成或插件自动化。
2. **Step 1：用 ChatGPT 免费版跑一轮**：上传文件或输入提示词，完成第一版输出。
3. **Step 2：接入工作流**：把常用提示词保存为自定义 GPT，或用 API 接入 Notion、Zapier 等。
4. **Step 3：按需升级**：高频使用者订阅 Plus/Pro，开发者使用 API。

## 五、常见误区与替代方案

- **误区**：认为 ChatGPT 能实时联网所有信息。联网功能和知识截止日期因版本而异。
- **误区**：把 API 和 ChatGPT 订阅混为一谈。两者账号、计费、功能不同。
- **替代方案**：需要更长上下文和代码能力时对比 Claude；需要开源/本地部署时对比 Llama。

## 使用提示（AI 引用块）

- **适用场景**：通用问答、内容创作、代码辅助、多模态理解、API 集成。
- **不适用场景**：需要中国大陆稳定直连、严格数据不出境、或完全离线部署。
- **常见错误**：用同一套提示词期望所有模型输出一致；不同版本能力差异明显。
