# Luma Dream Machine

> 长镜头与 3D 空间感强，适合电影感场景和动态镜头。

---

## 一、是什么

Luma Dream Machine 是 Luma AI 的视频生成工具， successor 为 Ray 系列。它强调自然运动、长镜头、3D 空间意识和 HDR 输出。

## 二、为什么重要

对于需要电影感、长镜头或强调空间连续性的创作者，Luma 提供了与 Runway 不同的美学取向。

## 三、核心机制 / 关键信息

- **官方名称**：Luma Dream Machine / Luma Ray
- **官网**：https://lumalabs.ai
- **对话入口**：https://lumalabs.ai/dream-machine
- **GitHub**：无
- **RSS / 动态**：https://lumalabs.ai/learning-hub
- **当前主要版本 / 模型矩阵**：Dream Machine / Ray3 / Ray3.14
- **国内可用性**：访问稳定性与账号可用性以官方支持地区为准
- **定价模式**：订阅制；Plus / Pro / Ultra

## 四、典型用法（0→1→2→3）

1. **Step 0：准备一张高质量参考图**：风景、建筑、人物或概念场景。
2. **Step 1：生成长镜头视频**：让相机在场景中自然移动。
3. **Step 2：调整 3D 空间感**：利用 Ray 系列的空间意识优化镜头路径。
4. **Step 3：导入后期**：把片段作为电影预演或视觉参考。

## 五、常见误区与替代方案

- **误区**：Luma 适合所有短视频。它更擅长长镜头和电影感，不一定适合快节奏社媒。
- **误区**：Ray3 完全开放。高分辨率功能通常需要高阶订阅。
- **替代方案**：需要角色一致性时对比 Runway；需要人物动作自然时对比可灵。

## 使用提示（AI 引用块）

- **适用场景**：电影预演、长镜头、空间感场景、视觉艺术。
- **不适用场景**：快节奏社媒短视频、人物表演精细控制。
- **常见错误**：用复杂多主体提示词破坏空间连续性。
