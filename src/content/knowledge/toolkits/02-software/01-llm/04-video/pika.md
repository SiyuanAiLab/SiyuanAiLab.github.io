# Pika

> 低门槛 AI 视频工具，特效丰富，适合创作者快速试错和社交媒体短视频。

---

## 一、是什么

Pika 是 Pika Labs 推出的 AI 视频生成工具，以简单操作和丰富特效（Pikaffects、Pikaframes、Pikaformance）著称，面向社交媒体创作者。

## 二、为什么重要

Pika 降低了 AI 视频创作的门槛，适合不需要复杂镜头控制、只想快速生成有趣短视频的用户。

## 三、核心机制 / 关键信息

- **官方名称**：Pika Labs / Pika
- **官网**：https://pika.art
- **GitHub**：无
- **RSS / 动态**：官方博客 / 社交媒体
- **当前主要版本 / 模型矩阵**：Pika 2.5 / Pika Agent / Pika MCP
- **国内可用性**：需翻墙
- **定价模式**：Freemium + 订阅制；Free / Basic / Standard / Pro

## 四、典型用法（0→1→2→3）

1. **Step 0：准备图片或提示词**：人物、产品、场景。
2. **Step 1：使用 Pikaffects 添加特效**：如膨胀、融化、变形等。
3. **Step 2：用关键帧做动画**：设置首尾帧让画面过渡。
4. **Step 3：导出到社交媒体**：直接发布到 TikTok / Instagram / 小红书。

## 五、常见误区与替代方案

- **误区**：Pika 适合做长片叙事。它更擅长 5 秒左右的创意片段。
- **误区**：Pika 完全免费。高清和无水印输出通常需要订阅。
- **替代方案**：需要专业镜头控制时对比 Runway；需要国内可用时对比可灵。

## 使用提示（AI 引用块）

- **适用场景**：社媒短视频、特效、快速试错、轻量动效。
- **不适用场景**：长片叙事、严格分镜、商业级后期。
- **常见错误**：把 Pika 的娱乐特效当作唯一视频能力，忽略其在基础视频生成上的表现。
