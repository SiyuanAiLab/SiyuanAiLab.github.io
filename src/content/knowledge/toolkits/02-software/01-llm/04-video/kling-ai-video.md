# 可灵 AI 视频

> 国内视频生成代表，人物动作自然、成本平衡好，适合短视频和电商素材。

---

## 一、是什么

可灵 AI 视频是快手可灵 AI 平台的视频生成能力，提供消费端产品和开放平台 API。它以人物动作自然、视频连贯性和中文场景适配著称。

## 二、为什么重要

对于国内短视频创作者、电商广告主和希望用中文提示词的用户，可灵 AI 提供了一个中文支持较完整、账号使用较便利的高质量视频生成选项。

## 三、核心机制 / 关键信息

- **官方名称**：可灵 AI（Kling AI）
- **官网**：https://klingai.com
- **开放平台**：https://kling.ai/dev/pricing
- **GitHub**：部分开源在 https://github.com/KwaiVGI
- **RSS / 动态**：快手官方公众号
- **当前主要版本 / 模型矩阵**：可灵 3.0 / 2.6 / O1 视频模型
- **国内可用性**：可用
- **定价模式**：Freemium + 订阅制 + API 套餐

## 四、典型用法（0→1→2→3）

1. **Step 0：准备创意描述**：人物、动作、场景、风格、运镜。
2. **Step 1：生成首版视频**：从图生视频或文生视频开始。
3. **Step 2：优化动作和运镜**：使用运动控制功能调整。
4. **Step 3：批量生产**：通过 API 批量生成广告或电商素材。

## 五、常见误区与替代方案

- **误区**：可灵只能做人物视频。它在产品、场景和运动控制上也有能力。
- **误区**：免费版足够商业使用。高清、长时长、高并发通常需要付费。
- **替代方案**：需要电影感镜头控制时对比 Runway；需要与剪映联动时对比即梦。

## 使用提示（AI 引用块）

- **适用场景**：短视频、电商视频、人物动作、广告素材、国内用户。
- **不适用场景**：需要电影级叙事、严格分镜控制、完全离线生成。
- **常见错误**：提示词主体过多导致画面崩坏，建议从单主体动态开始测试。
