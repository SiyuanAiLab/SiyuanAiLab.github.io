# Atlassian Confluence

> 企业知识库和研发协作成熟工具，适合 Jira / Atlassian 体系内团队。

---

## 一、是什么

Atlassian Confluence 是企业级知识库和团队协作工具，与 Jira、Bitbucket、Trello 同属 Atlassian 生态。它适合存放需求文档、技术文档、会议记录和项目 Wiki。

## 二、为什么重要

对于已经在使用 Jira 进行项目管理的研发团队，Confluence 提供了无缝的需求-文档-任务联动，减少了工具切换。

## 三、核心机制 / 关键信息

- **官方名称**：Atlassian Confluence
- **官网**：https://www.atlassian.com/software/confluence
- **GitHub**：无
- **RSS / 动态**：https://www.atlassian.com/blog/confluence
- **当前主要版本 / 模型矩阵**：Confluence Cloud、页面协作、白板、数据库、Atlassian Intelligence / Rovo
- **国内可用性**：官网可访问，但 Atlassian Cloud 在中国大陆的网络、合规和购买需企业单独验证
- **定价模式**：Freemium + 按席位订阅

## 四、典型用法（0→1→2→3）

1. **Step 0：创建空间**：按项目或团队划分。
2. **Step 1：建立模板**：需求文档、会议纪要、 retro 模板。
3. **Step 2：与 Jira 联动**：在 Confluence 页面中引用 Jira issue。
4. **Step 3：启用 Rovo AI**：用 AI 搜索和总结知识库内容。

## 五、常见误区与替代方案

- **误区**：Confluence 只适合技术团队。任何需要结构化文档的团队都可以使用。
- **误区**：Confluence 很便宜。按席位订阅对大中型团队成本不低。
- **替代方案**：需要更现代用户体验时对比 Notion；需要国内生态时对比飞书知识库。

## 使用提示（AI 引用块）

- **适用场景**：Jira 用户、企业知识库、研发文档、技术 Wiki。
- **不适用场景**：没有 Atlassian 生态、预算有限、追求轻量体验。
- **常见错误**：空间结构混乱，页面层级过深，导致检索困难。
