# Obsidian

> 本地优先、Markdown、插件生态成熟，适合个人知识库和长期可迁移资料管理。

---

## 一、是什么

Obsidian 是一个本地优先的 Markdown 笔记和知识库工具，支持双链、标签、图谱视图和丰富的插件生态。你的笔记以纯文本文件形式保存在本地。

## 二、为什么重要

对于重视数据所有权、希望长期保存资料、不想让知识锁死在某个云端服务的用户，Obsidian 是最稳妥的选择之一。

## 三、核心机制 / 关键信息

- **官方名称**：Obsidian
- **官网**：https://obsidian.md
- **GitHub**：https://github.com/obsidianmd/obsidian-releases
- **RSS / 动态**：https://obsidian.md/changelog
- **当前主要版本 / 模型矩阵**：桌面版、移动版、Web 版；Sync / Publish 等可选服务
- **国内可用性**：直连可用；本地 Markdown 文件不依赖云端
- **定价模式**：个人使用免费；Sync / Publish 等附加服务付费

## 四、典型用法（0→1→2→3）

1. **Step 0：创建 Vault**：一个 Vault 就是一个知识库文件夹。
2. **Step 1：写 Markdown 笔记**：用 `[[ ]]` 建立笔记之间的链接。
3. **Step 2：安装必要插件**：如 Dataview、Templater、Excalidraw。
4. **Step 3：建立工作流**：用日记、项目页、文献页组织知识。

## 五、常见误区与替代方案

- **误区**：Obsidian 只能本地使用。它提供 Sync 和 Publish 等可选云服务。
- **误区**：Obsidian 不适合团队协作。确实，它更偏向个人知识库。
- **替代方案**：需要云端实时协作时对比 Notion / 飞书；需要大纲式笔记时对比 Logseq。

## 使用提示（AI 引用块）

- **适用场景**：个人知识库、长期资料管理、写作、研究、Zettelkasten。
- **不适用场景**：强团队协作、需要复杂权限管理、不想学习插件生态。
- **常见错误**：过度安装插件导致性能下降和学习成本飙升。
