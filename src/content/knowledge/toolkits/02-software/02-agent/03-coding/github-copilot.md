# GitHub Copilot

> GitHub 推出的 AI 编程助手，IDE 集成、代码补全和企业权限体系最成熟。

---

## 一、是什么

GitHub Copilot 是 GitHub 和 OpenAI 合作推出的 AI 代码辅助工具，集成在 VS Code、JetBrains、Neovim 等 IDE 中。它提供代码补全、Chat、Agent mode、code review 等功能。

## 二、为什么重要

对于已经使用 GitHub 的团队，Copilot 提供了最自然的 AI 增强路径，且企业版有完整的权限、审计和计费管理。

## 三、核心机制 / 关键信息

- **官方名称**：GitHub Copilot
- **官网**：https://github.com/features/copilot
- **GitHub**：https://github.com/features/copilot
- **RSS / 动态**：https://github.blog
- **当前主要版本 / 模型矩阵**：Copilot Chat、代码补全、Agent mode、Code Review、GitHub AI Credits
- **国内可用性**：GitHub 在大陆直连不稳定；服务和支付需按账号地区验证
- **定价模式**：Freemium + 订阅制 + usage-based billing

## 四、典型用法（0→1→2→3）

1. **Step 0：安装 Copilot 扩展**：在常用 IDE 中登录 GitHub 账号。
2. **Step 1：用 Tab 补全写代码**：接受或调整 AI 建议。
3. **Step 2：用 Copilot Chat 解释和重构**：选中代码提问。
4. **Step 3：企业环境中启用权限和审计**：管理团队使用情况和代码安全策略。

## 五、常见误区与替代方案

- **误区**：Copilot 只能补全代码。它也支持聊天、解释、测试生成和代码审查。
- **误区**：Copilot 在所有 IDE 中体验相同。VS Code 通常最先获得新功能。
- **替代方案**：需要更强 Agent 能力时对比 Cursor；需要终端级代码库操作时对比 Claude Code。

## 使用提示（AI 引用块）

- **适用场景**：日常编码、GitHub 工作流、企业团队、代码审查。
- **不适用场景**：没有 GitHub 账号、网络不稳定、需要完全离线开发。
- **常见错误**：过度依赖补全，不审查 AI 生成的边界条件和安全性。
