# Cursor

> AI 原生 IDE，代码补全、重构、Agent 和代码库理解能力强。

---

## 一、是什么

Cursor 是一个基于 VS Code 的 AI 原生 IDE，提供 Tab 补全、Chat、Composer、Agent 模式等功能。它能理解整个代码库，执行跨文件修改和重构。

## 二、为什么重要

Cursor 把 AI 从“辅助写代码”推进到“参与整个开发流程”，包括需求理解、代码生成、测试、调试和重构。

## 三、核心机制 / 关键信息

- **官方名称**：Cursor
- **官网**：https://cursor.com
- **GitHub**：无
- **RSS / 动态**：https://cursor.com/blog
- **当前主要版本 / 模型矩阵**：AI IDE，支持多模型、Tab 补全、Agent、Bugbot
- **国内可用性**：需翻墙
- **定价模式**：Freemium + 订阅制 + usage；个人 Pro / Pro+ / Ultra，Teams 计划

## 四、典型用法（0→1→2→3）

1. **Step 0：迁移现有项目**：Cursor 兼容 VS Code 插件和配置。
2. **Step 1：用 Tab 补全加速日常编码**：接受、部分接受或忽略建议。
3. **Step 2：用 Chat 解释和修改代码**：选中代码块提问或直接要求修改。
4. **Step 3：用 Agent 模式完成完整功能**：描述需求，让它跨文件实施并运行测试。

## 五、常见误区与替代方案

- **误区**：Cursor 会完全替代开发者。它提高的是效率，不是决策质量。
- **误区**：Cursor 免费版无限使用。Agent 和高级模型调用通常受额度限制。
- **替代方案**：需要终端级代码库操作时对比 Claude Code；需要 GitHub 原生集成时对比 Copilot。

## 使用提示（AI 引用块）

- **适用场景**：全栈开发、代码重构、学习新代码库、快速原型。
- **不适用场景**：简单脚本、对 AI 生成代码不信任、没有代码审查流程。
- **常见错误**：直接接受 Agent 模式的大量修改而不做 diff 审查。
