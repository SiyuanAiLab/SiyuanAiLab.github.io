# 工具配置与选型

面向非技术初学者和创业者的 AI 工具配置与选型指南：先判断自己真正要解决的问题，再按场景、角色和预算选择合适的软件与硬件。

## 三大板块

- **选型决策**：先建立判断框架，回答“我该先解决什么问题”“我是谁、该用什么”“工具值不值得买”。
- **软件选型**：覆盖大语言模型、图像/视频生成、Agent 框架、代码型 Agent、知识库、AI 搜索和效率创作工具。
- **硬件选型**：覆盖录音语音采集、视觉可穿戴和生命体征监测设备，服务内容生产、移动办公和个人状态管理。

## 子分类入口

- [选型决策](/knowledge/toolkits/use-case-first/)：从用例、角色、评估维度和最小路径开始。
- [大语言模型与生成工具](/knowledge/toolkits/openai-chatgpt/)：从 ChatGPT、Claude、Gemini、Qwen、DeepSeek 到图像和视频生成模型。
- [Agent、知识库与搜索工具](/knowledge/toolkits/langchain-langgraph/)：从 Agent 框架、代码型 Agent 到知识库软件和 AI 搜索。
- [效率创作与硬件选型](/knowledge/toolkits/capcut/)：从剪辑、设计、语音、演示，到录音设备、可穿戴和健康监测。

## 阅读方式

如果你还没有明确工具目标，先读“选型决策”四张卡，确定任务和角色；如果你已经知道要做什么，直接按目录进入软件或硬件分类；如果你在替团队采购或搭建工作流，优先阅读评估框架、Agent、知识库和搜索工具相关卡片。
